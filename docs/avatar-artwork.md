# Avatar artwork

Twelve built-in cartoon profile choices. Cowgirl and Astronaut are adult women characters.

Generated with the built-in ImageGen tool. Source PNGs are retained in `static/avatars/source/`; optimized256px thumbnails in `static/avatars/` and1024px display masters in `static/avatars/full/`. Runtime admin additions are stored outside source in the room data directory.
